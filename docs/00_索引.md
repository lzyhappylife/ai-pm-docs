## 使用说明

1. **不要跳过任何一份**：每份 SKILL 都是前一份的输入。产品总纲是所有 PRD 的依据，用户调研是产品总纲的输入，功能排期表是 PRD 的索引。
2. **先选粒度再动笔**：01（产品总纲）和 03（竞品分析）和 07（评测报告）开篇都有"先选模式/刀法/范式"决策表，先看你当前属于哪种情况，再套对应框架。
3. **Prompt 模板直接用**：每份 SKILL 第六章有可直接复制的 Prompt，把 `{占位符}` 替换成你的项目信息喂给 AI，能快速生成初稿，再按 Checklist 逐项打磨。
4. **品类差异化别忘了**：每份 SKILL 第四章都列了 A/B/C/D/E 五类产品的差异化注意事项，套框架时必须对照你所属类别调整。
5. **持续完善**：本批次是第一版。每次写完真实项目后，把新的经验、踩过的坑、更好的写法回写到对应 SKILL 文件里，让模板越用越准。
