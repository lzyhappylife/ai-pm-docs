# ai-pm-docs

> AI 产品 0→1 落地文档生成助手 — 为 Doubao / 豆包办公设计的 Skill

一份覆盖 AI 产品从立项到上线全流程的 **27 份文档模板与写作框架**，内置在豆包 Skill 体系中，根据用户要写的文档类型自动加载对应子文件，避免上下文过载。

## 它能帮你写什么

| 阶段 | 文档 | 适用场景 |
|------|------|---------|
| **立项调研** | 行业调研报告、单品竞品分析、多品竞品横向对比、功能分析报告 | 看大盘、拆竞品、找机会 |
| **用户研究** | 用户访谈记录、问卷调查、用户画像、用户调研报告 | 深访 / 量化 / Persona / 汇总 |
| **产品定义** | 产品总纲（立项报告）、PRD、功能排期表、验收表 | 从 0 到 1 定义产品 |
| **Agent / RAG 专项** | Agent 需求文档、RAG 需求文档 | 智能体与知识库场景 |
| **模型评测** | 评测报告、Agent 评测报告、Case 表、评测集、通用评测标准、模型评测总览、RAG 评测三件套 | 模型选型、效果验证 |
| **上线运营** | 数据埋点表、测试反馈表、VOC 用户声音表 | 埋点、反馈、用户声音闭环 |
| **个人管理** | 产品个人清单 | PM 自己的 To-do |

每份子文件都包含：**资料清单 → 框架结构 → 颗粒度要求 → 品类差异化 → Checklist → Prompt 模板**。

## 产品分类（差异化写作）

Skill 会根据你的产品类型自动调整写作侧重点：

- **A 类**：对话式 AI / Agent（多轮对话、Tool use、人设、长期记忆）
- **B 类**：RAG 知识库 / 问答（检索增强、引用溯源）
- **C 类**：AIGC 多模态生成（提示词组装、多模型 fallback）
- **D 类**：AI 评测平台 / 内部工具（Golden Set、LLM-as-Judge）
- **E 类**：B 端 SaaS / 传统产品 AI 化（商户场景、工单驱动）

## 安装方式

### 在豆包办公中使用

将整个 `ai-pm-docs/` 目录放入你的用户 Skill 目录：

```
~/.doubaowork/agent_mode/workspace/.user_skills/ai-pm-docs/
├── SKILL.md
└── docs/
    ├── 00_索引.md
    ├── 00_信息源导航.md
    ├── 01_产品总纲_产品基建文档.md
    ├── 02_PRD产品需求文档.md
    └── ...（共 28 份子模板）
```

然后在对话中直接说"帮我写一份 PRD"或"做个竞品分析"即可触发。

### 自己参考使用

即使不装在豆包里，所有模板都是独立的 Markdown 文件，你也可以直接拿去自己写文档时参考框架和 Checklist。
